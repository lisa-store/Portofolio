# Website Portofolio UAS — HTML, CSS & JavaScript

Website statis, responsif, dan siap diunggah ke Netlify. Tidak memerlukan database, Python, Laravel, atau instalasi npm.

## 1. Cara menjalankan di laptop

1. Ekstrak folder `portfolio-uas`.
2. Buka folder menggunakan Visual Studio Code.
3. Buka `index.html` di browser (klik dua kali), atau gunakan ekstensi Live Server.

## 2. WAJIB: Ganti data contoh

Semua informasi awal adalah **CONTOH** dan **BELUM MENGGUNAKAN IDENTITAS ASLI**. Buka `data.js`, lalu ubah:
- `name`, `initials`, `role`, `headline`, `introduction`, `about`, `location`
- `email`, akun media sosial dan link hasil karya
- `skills`, `education`, `experience`, `projects` (hapus contoh yang tidak sesuai)
- Opsional: simpan foto di `assets/foto-profil.jpg`, lalu isi `photo: "assets/foto-profil.jpg"`
- Opsional: simpan CV di `assets/CV.pdf`, lalu isi `cv: "assets/CV.pdf"`

Jangan mengklaim skill/pengalaman/proyek contoh sebagai prestasi sendiri.

## 3. Cara hosting Netlify (paling mudah)

1. Pastikan file `index.html`, `style.css`, `script.js`, dan `data.js` berada langsung di dalam folder `portfolio-uas`.
2. Kunjungi https://app.netlify.com/drop
3. Masuk atau buat akun agar kamu bisa mengelola situs.
4. Seret dan lepas folder `portfolio-uas` ke halaman tersebut (atau upload ZIP bila tersedia).
5. Setelah berhasil, gunakan URL `*.netlify.app` yang diberikan Netlify.
6. Tes website di HP dan laptop, semua link, lalu kirim URL ke dosen.

**Catatan:** Setiap kali ada perubahan data, lakukan deploy ulang folder terbaru jika menggunakan manual deploy.
